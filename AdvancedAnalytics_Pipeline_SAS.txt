**Advanced Analytics Pipeline using SAS PROC SQL + Python AI**.
This approach combines the strengths of **SAS** (data processing & governance) with **Python** 
AI tools such as **PySAS**, **pandas**, and **scikit-learn**.

This architecture is commonly used in **banks for fraud detection, credit scoring, and customer analytics**.

# 4. Data Preparation with PROC SQL (Banking Example)

Example dataset: **Credit Card Transactions**

```sql
proc sql;
create table work.customer_features as
select 
    customer_id,
    count(*) as txn_count,
    sum(amount) as total_spend,
    avg(amount) as avg_spend,
    max(amount) as max_txn
from bank.transactions
group by customer_id;
quit;
```

### What this does

| Feature     | Purpose              |
| ----------- | -------------------- |
| txn_count   | Transaction behavior |
| total_spend | Spending capacity    |
| avg_spend   | Customer profile     |
| max_txn     | Fraud signal         |

---

# 5. Run PROC SQL from Python

```python
sas_code = """
proc sql;
create table work.customer_features as
select 
    customer_id,
    count(*) as txn_count,
    sum(amount) as total_spend,
    avg(amount) as avg_spend,
    max(amount) as max_txn
from bank.transactions
group by customer_id;
quit;
"""

sas.submit(sas_code)
```

---

# 6. Transfer Data to Python

```python
df = sas.sasdata2dataframe(table="customer_features", libref="work")
print(df.head())
```

Now the dataset is available for **AI modeling**.

---

# 7. Build AI Model (Fraud Detection Example)

Using **scikit-learn**

```python
X = df[['txn_count','total_spend','avg_spend','max_txn']]
y = df['fraud_flag']

X_train, X_test, y_train, y_test = train_test_split(X,y,test_size=0.2)

model = RandomForestClassifier()

model.fit(X_train,y_train)

predictions = model.predict(X_test)
```

---

# 8. Model Evaluation

```python
from sklearn.metrics import accuracy_score

print("Accuracy:", accuracy_score(y_test,predictions))
```

Banks usually monitor:

| Metric    | Meaning                     |
| --------- | --------------------------- |
| Accuracy  | Overall correctness         |
| Precision | Fraud detection reliability |
| Recall    | Catching fraud cases        |

---

# 9. Send AI Predictions Back to SAS

```python
df['fraud_prediction'] = model.predict(X)

sas.df2sd(df, table='fraud_results', libref='work')
```

Now SAS can generate **regulatory reports**.

---

# 10. SAS Reporting

Example:

```sql
proc sql;
select fraud_prediction, count(*) 
from work.fraud_results
group by fraud_prediction;
quit;
```

This creates **risk monitoring reports**.
