

1: Metrics (Top Cards)

Total Cost = SUM(Sales[Total Cost])
2. Total Sales
Total Sales = SUM(Sales[Total Sales])
3. Total Discount
Total Discount = SUM(Sales[Total Discount])
4. Total Profit
Total Profit = SUM(Sales[Total Profit])

2: Charts
5. Sum of Total Sales by Region (Pie Chart)
	Values: Total Sales
	Legend: Region
Improved DAX (if you want dynamic title or filtering):
Sales by Region = 
CALCULATE(
    [Total Sales],
    ALLEXCEPT(Sales, Sales[Region])
)

6. Sum of Total Cost by State (Bar Chart)
	Axis: State
	Values: Total Cost
DAX (sorted):
You can sort by descending cost using:
Total Cost by State = 
SUM(Sales[Total Cost])

7. Total Cost by Segment (Donut Chart)
	Legend: Segment
	Values: Total Cost

8. Profit by Sub-Category (Bar with values)
This likely uses:
	Axis: Sub-Category
	Values: Total Profit
To create a measure with formatting, use:
Formatted Profit = 
FORMAT(SUM(Sales[Total Profit]), "₹#,##0")

  "background": "#000000",

        "color": { "solid": { "color": "#FFC300" } },

1.	Go to View > Themes > Browse for Themes in Power BI
2.	Load this .json file
 IMPROVED / ADVANCED DAX IDEAS
1. Profit Margin
Profit Margin = DIVIDE([Total Profit], [Total Sales], 0)
2. Top N Sub-Categories by Profit
Top N SubCategories = 
TOPN(
    5,
    SUMMARIZE(Sales, Sales[Sub-Category], "Profit", [Total Profit]),
    [Total Profit],
    DESC
)
3. Dynamic Title Example
Title_SelectedRegion = 
"Total Sales in " & SELECTEDVALUE(Sales[Region], "All Regions")
Use this measure in a Card Visual as a dynamic title.
